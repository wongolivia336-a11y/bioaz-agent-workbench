# 同日补丁二：站内信复核画布里，计算表的明细压到参数表底下

用户截图：报价复核 → 计算表，左边的计价明细和右边的可编辑参数叠在一起。

## 原因

复核画布里那张纸只有 644 宽（右边还有人工批注栏），明细栏分到 307px。auto 布局的表格宽 = 各列最小宽度之和，
只要这个和超过 307，表格就从栏里溢出去、画在参数表底下——溢出不裁。三样东西把最小宽度撑到了 374：

1. 单价下面那行小注（P0-2 加的 `.quoteNumNote`）写了 `nowrap`，「In life -TOX- (per animal/week)」一行就是 200px。**主因，是我这轮加的。**
2. 条目名 `<strong>` 和说明 `<small>` 是两个 inline 元素挨着，「Species and strain」+「C57」连成一个词 "strainC57"——最小宽度按这个词算。这条是原来就有的（`.quoteCellButton` 那套样式定义了但 markup 没用上）。
3. 分类名 `nowrap`，「Clinical Pathology」不折就是 130px。

## 改法

不动表格布局（auto 照旧，宽屏下和原来一样），只把最小宽度压下去：小注允许折行、上限 128px 靠右；条目名和说明各占一行；
计算表里的分类名允许折行。改完明细表 307 = 栏宽，不再溢出；顺手把 "strainC57" 那种连字修了。

## 验收

1440 宽进 站内信 → 待确认：Balb/c nude 报价交付包 → 开始审核 → 计算表：明细表宽 307.45 = 栏宽，`overlap: false`，
参数表也没溢出纸边。
