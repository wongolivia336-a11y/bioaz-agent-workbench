# 2026-09-21 · 空间首页第三版：层级重排

用户看着预览提了两条：进了空间还挂着空间选择器，多余；页面信息层级不好，可以加 icon / 插画。

## 判断

- **选择器该去掉。** 面包屑写着空间名，选择器和它上面那行「你想在 X 中完成什么任务？」把同一件事说了三遍。进了空间，空间就是定的；要换去侧栏。选择器只留给全局首页。
- **层级问题的根子是七张卡一样重。** 四张专家卡 + 三张概览卡同一副边框、同一档字号，看不出谁是动作、谁是说明。
  顶上那个大 logo 是全局首页的品牌时刻，放在空间首页上主角就成了 BioAZ 而不是这个空间。

## 改了什么

| 位置 | 之前 | 现在 |
|---|---|---|
| 顶部 | BioAZ logo | 一张细线插画 `SpaceMark`（文件夹 + 文件 / 任务 / 专家三个节点，虚线连回，一处品牌紫）+ 一枚标签「客户空间 · 3 个任务」 |

文件：`components/hero/SpaceMark.tsx`（新）、`NewTaskHome.tsx`、`WorkbenchShell.tsx`（传 `spaceKind`）、`globals.css`。

# 同日第四版：专家可配、卡有底纹、hover 介绍、概览成卡、紫色收一收

用户看了第三版又提了四条：这一页能不能直接配专家；专家卡里放一张任务角色的底纹插画；紫色太多太油、扫光柔一点；
概览也再推敲，hover 上去要有一张「灵动的」介绍卡，卡片同样要有 svg。中途一句「首屏不要改」，我已经把卡片的紫收成了全局的，
用户看了首屏之后说「现在这样可以不要撤回」——所以紫色那三处是全局的，其余全在 `isSpaceHome` 之下。

## 改了什么

| 位置 | 做法 |
|---|---|
| 眉题行 | 「本空间的专家」左，「配置专家」右，开的是侧栏 … 菜单那张同一个弹窗。`SpaceCoworkerDialog` 从 `WorkspaceSidebar.tsx` 抽到自己的文件，两处 import。宽度公式跟卡片网格同一个（几张卡 × 215px），三张卡时也对得齐 |
| 专家卡底纹 | `components/hero/RoleMotif.tsx`：按 moduleId 一张线稿（试管+价签 / 报告页+趋势线 / 细胞簇+价签 / 盾+勾），绝对定位右下角，`currentColor` = `--review-line`，hover 深一档仍是灰 |
| hover 介绍卡 | 放在 button 里的 `span.expertIntro`（button 里只能放短语内容），空间首页的卡 `overflow: visible`。内容全从模块定义上取：`suggestedCoworker.description` + `stages` 标签 + `artifacts` 标签，壳层拼进 `QuickStartItem.intro`。开在卡**下方**盖住输入框——先做的上方，盖住大标题黑字被截一半，比盖住空输入框难看得多。进场 `cubic-bezier(.2,.9,.3,1.15)` 一点回弹，流程 chip 按 `--i` 依次亮 |

## 踩到的

- **输入框那一栏 z-index 20**（它的菜单要压过介绍区）。介绍卡开在它上面，`.newTaskIntro` 只有 z-index 1 → 被压在下面。
  用 `.newTaskIntro.isSpaceHome:has(.taskExampleGrid button:hover) { z-index: 21 }` 只在 hover 时抬，常态仍让输入框的菜单压过来。
- `pointer-events: none` 的元素 `elementFromPoint` 会穿过去——验 z-order 时得临时把它打开再测，不然永远"被压住"。
- 浏览器面板在后台时 rAF 停摆，transition 永远停在起点：验 hover 态要临时 `transition: none` 再读 computed。
- 图标方块的底色其实是 `new-task-home.css` 里后加载的 `color-mix(5% 品牌色)` 定的，review.css 写什么都不生效——把 review.css 里那句删了、留注释指过去，不留一句骗人的 CSS。
- `audit:ui` 把 `120ms / 160ms / 220ms` 算成三种新时长——这几个文件里以前从来没写过字面量，全是 `var(--bioaz-motion-*)`。改回令牌，只剩 selectors +38 和 keyframe +1（`expertIntroChipIn`）是有意的，`--update`。
- dev server 的 watcher 漏了几次改动（G: 盘 + webpack cache 报 snapshot 失败），浏览器一直是旧包。停了重开就好。
