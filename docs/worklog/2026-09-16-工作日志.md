## 踩到的

- 「报价区域国内」这句一句话识别不认：`parseDmpkRequest` 从来没有 region 规则（语言、格式有，区域没有）。
  于是核对那条路对「区域」永远找不回。它在「不动」清单里，先记着，要单独拍板。
- `recheckSources` 读的 `messages` 是闭包里的，触发它的那条用户消息还没进去——「回读 N 条对话」少算 1 条。演示无碍，真接后端时按消息 id 取。
- 会话面板只渲染当前 tab 的内容：验 toolbar 要先切回「参数收集」，验版本卡要先切到「报价结果」。
