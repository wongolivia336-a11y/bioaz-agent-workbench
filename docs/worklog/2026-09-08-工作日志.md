## 一、设计系统：能对外看了

### 1. 站点不再点评原型

原来站上到处在报数——53 处裸按钮、45 个关键帧、一张卡 76 条规则、
「没人决定过」。数字都是真的，但**不该放在一个要对外展示的页面上**：
规范的说服力应该来自它自己讲得通，不是来自数别人的错。

全部搬进 `docs/工程债.md`（原型仓库），在那儿是待办清单，每条后面写了
「怎么算还清」。站上留下的只有规则本身和为什么。改了 8 个页面。

### 2. 左边那道色线全去掉（老师说的"AI 味"）

- 退回处理卡：原型是四边同色 1px 边，**没有色线**，「必须修订」靠右上角
  角标换底色说。库里那道 3px 琥珀是凭空加的。
- 退回事件、站点自己的说明块：同样删掉。
- 量过一遍：现在页面上**没有任何元素的左边框跟其它三边不同**。

### 3. 图标"乱码"找到原因了

**它们在按 2px 描边渲染。** 库里那条 1.75 的规则只挂在一个组件上，
其余全部退回图标库默认的 2——在 13~16px 上会把镂空处糊死，
一排小图标看过去就是一排黑点。原型是全局 1.75，库里补上了。
现在全站 29 个图标：21 个 1.75，8 个 2.3（11px 的叉号，刻意加重）。

### 4. 外壳演示两个模块重叠

演示默认就开着"并列"，面板为了塞下两列自己撑到 656px，比工作区还宽。
并列是个能力，不是默认状态，改成默认单列。

顺带量出一个真 bug：面板的隐式网格列按 max-content 撑，三个标签加按钮
508px 而面板只有 320px，**内容整个溢出压在工作区上**。现在溢出 0。

### 5. 「约定」补了缺的一节

原来是：交互状态 / 刻度 / Hover / 动效 / 折叠 / 图标。
**缺「键盘与浮层」**，而三个 hook 早就在仓库里、只是没有页面。补上：
Esc 只关最上面一层、遮罩用 mousedown 不用 click、方向键循环且跳过禁用项、
Enter 发送先判 `isComposing`。

## 二、肿瘤报价：回到 DMPK 的形状

老师指出工程师那版和 DMPK "不是一个路数"，我之前也有几处自己加多了。

### 1. 去掉 composer 下面那颗开关按钮

DMPK 的参数卡本来就是折叠态（一次列一组，点卡片展开成全屏），
收集完就收起。我加那颗开关是为了解决「填完想回头改没入口」——
**但那个入口本来就有**：右栏台账每行的铅笔。多一颗按钮换来两条线不一致，
而它解决的问题不存在。

去掉之后量过：848px 宽、8px 圆角、1px 边、`12px 14px` 内距、gap 18、
四个分页——**跟 DMPK 逐项相同，差异 0 项**。

### 2. 去掉「修改日志」和「当前报价表」两个 tab

这两个是工程师那边的方向，逻辑上跟 DMPK 对不上：
- 参数怎么变成钱 → 该看**报价规则**
- 谁改了什么 → 对话流里本来就是一条条消息，再开一个 tab 抄一遍，
  同一件事记两处，迟早对不上

工程师那张报价表没丢，变成规则面板上的「查看费用明细」弹窗——
看一眼就关的东西不值得长期占一个 tab。

### 3. 换成 DMPK 的「报价规则」面板

同一套分层：上半段**本次命中的规则**（有边框、可改，「改这条」把话填进
composer，入口回到中间对话流），下半段**全局规则**（只读，链到报价管理后台）。
规则是从参数算出来的，改了品系那行金额跟着动。

### 4. 文案统一

台账标题「参数台账」→「参数收集」，跟 DMPK 逐字一致。tab 名同。

### 5. tab 并列按钮点不动 —— 确实是 bug，三层

- 按钮置灰看的是 `capacity`（**当前宽度**排得下几列），拖拽看的是
  `canSplitMore`（**加宽之后**排得下几列）。面板默认 320，capacity 恒为 1，
  **这颗按钮从来就是灰的**——所以只能拖。同一个动作两条路两套判据，
  其中一条永远不通。
- 判据当场量父容器，但只观察了面板自己；面板宽度被 clamp 在 320~760，
  **拉宽窗口面板一个像素都不变**，没有重渲，按钮一直按窗口还窄时的结论。
- `widenFor` 设完宽度等 ResizeObserver 回来告诉它刚设了多少，
  **第一次点会变成「面板变宽了但列没出来」**，要点第二次。

设计系统那份**按钮判据本来是对的**（只有原型漂了），另外两个坑它也有，
一起修了同步推上去。
