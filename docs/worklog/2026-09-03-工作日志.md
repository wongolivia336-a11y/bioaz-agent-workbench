# 2026-09-03 · 肿瘤报价接入，参数卡抽成公共组件

## 这轮做完的事

工程师的肿瘤报价 beta3 在形式上跟 DMPK 不是一路：下拉框长表单、空表单上先铺一片
红字、台账每行挂「未提交」。要的是**样式统一**。

评估结论是：方向对，但「复制 DMPK 改文案」这个动作行不通，要换成「共用一套组件」。
三个数字支撑这个判断：

- `.dmpk-quotationModuleShell` 在 CSS 里出现 **123 次**（review.css 116、
  session-column.css 3、iteration.css 2、responsive.css 2）。
- responsive.css 第 51 / 68 行是写死的 `:is(.dmpk-quotationModuleShell,
  .tumor-reportModuleShell)` 白名单。新模块不在里面，**窄屏会静默塌掉，不报错**。
- 参数卡的样式散在四个全局表里（review.css 199 处命中、globals.css 45、
  iteration.css 32、composer-chips.css 14），没有模块级样式表可以整个搬走。

所以做的是：

1. **`components/params/`**（新）——参数卡、行渲染器、chips 托盘、右栏台账全部
   数据驱动，类名一个没改。DMPK 和肿瘤报价共用这一份。
2. **`components/ui/PreviewModal.tsx`**（新）——`.previewModal` 那层皮的公共外壳。
   参数全屏面板、DMPK 报价前预览、肿瘤报价预览原本各手写一遍遮罩和关闭键。
3. **`modules/tumor-quotation/`**——从 placeholder 变成可用模块。
4. **`AgentModuleDefinition.shellVariant`**（新字段）——借另一个模块的外壳类名。
   肿瘤报价挂 `tumor-quotationModuleShell dmpk-quotationModuleShell` 两个类。

## 不要推翻的设计决定

**参数行有五种 kind，不要强行统一成选项按钮。**
实测：把肿瘤那 8 个中英双语模型选项塞进 `.optionGrid`（可用宽 795px），渲染出来
**127px 高、折 4 行、最宽一项 437px**；DMPK 现在一行 28px。长选项必须走下拉。
「统一」落在行的骨架上（序号 / 标签 / 必填 chip / 间距 / 选中态），不落在控件类型上。
量出来的对齐结果：所有控件 8px 圆角、12px 字号、`0 9px` 内距、0.8px 边框；
选项按钮 28px、输入类 30px。

**空表单上不铺红字。** beta3 在一张还没动过的表单上先挂五条「缺少必选参数」。
没填不等于填错。缺多少写在卡头的「还需填写 N 项」上，红字留给真正的冲突。
依赖没满足时给的是中性灰占位（「请先选择模型」），不是错误。

**待发状态只在 composer 的 chips 上。** 右栏台账只显示已落库的取值。
beta3 两边都标，人得自己判断哪个是真的。

**`shellVariant` 借类名，不要改成 123 条 `:is()` 白名单。**
白名单漏掉的那几条不会报错，只会在某个断点上塌掉。借类名是一行代码。

**依赖失效要清空并说出来。** 改了模型，原来选的品系在新模型下可能根本不存在。
悄悄留着的后果是报价按一个下拉里已经没有的取值算出来。现在会清空并回一句
「动物品系、细胞系在新的模型下已不适用，已清空待重选」。

**`allowCustom` 是按项开的，缺省关。** 封闭词表（报告格式、分析方法）多一个自定义
出口，等于邀请人写出系统认不了的取值。DMPK 开的仍是原来那五项：每组动物数、
组数、试验周期、采血点数、待测物数量。

## 新踩到的坑

**`.warningDecisionList span { color: var(--amber) }`（globals.css:2588）和
`.parameterTaskCard .decisionCopy span { font-size:12px }`（review.css:6001）
是按标签名写的。** 在参数行里新加一个裸 `<span>` 会被染成琥珀色粗体，而且
review.css 在 iteration.css 之后加载、特异性还更高，覆不回来。
新元素一律用带类名的 `<em>` / `<b>` / `<div>`。已有的 `.requiredTag` 是 `<span>`，
那是历史，照原样留着。

**重复行的表头和数据行必须共用同一条 grid 规则。** 分开写、任何一格是 `auto`，
两个 grid 就各算各的宽度，永远对不上。现在实测两者都是
`281.475px 234.562px 234.562px 26px`。

**解析器的老坑又踩了一次。** 「…，4 周，口服 qd」里的周期原来认不出来——
只认「周期 4 周」这种带前缀的写法。跟 DMPK 当初在采血点上栽的是同一个坑：
客户就是会用另一种语序，认不出来看着像系统没读懂他。
修法是加裸 `(\d+)\s*周` 兜底，同时挡住「每周两次 / 2 周一次」这类频率说法。

**`joinRepeat` 的尾部空格子要去掉。** 只填了第一格会序列化成 `Vehicle::`，
chip 上就是一串没意义的冒号。中间的空位要留着——那是位置信息。
