DMPK 报价：
原型 与 beta5
差在哪

先完整演示一遍原型（15 分钟），再回到这份讲稿逐页对照。结论先说：会话层同源，壳层跟着 beta5 改名，其余是我们多出来的。

一页结论

三句话

01 · 同源

会话层是同一套设计

三栏、对话流、参数卡、右栏、产物卡——beta5 已经采用了我们的会话设计。演示里看到的会话骨架，两边一样。

02 · 跟着改

壳层只改了名字和一页

「项目」→「空间」；进空间先到一个入口页；数据中枢多一档「产物」。侧栏结构、知识库、数字团队没动，会话层一个像素没动。

03 · 多出来

八件事 beta5 里没有

  • 右栏「报价板块」：参数状态 + 单价
  • 临时改价闭环、无价目补价
  • 价目表独立入口 + 对话里问本单价目
  • 多模态材料识别 + 原文依据 + 确认两态
  • 人 / 站内信 / 工单 / 交接 / 退回 / 复核画布
  • 演示级权限（SD / SD 助理）
  • 「+」菜单：技能 = 让它做，连接器 = 它在读什么
  • 空间首页的专家绑定与介绍
硬冲突只有一处：beta5 没有「人」。以我们为准。2
壳层

空间与入口页beta5 把项目改成了空间，每个空间先落到一个「我能为你做什么」的入口页——我们照做，但把这一页做成了这个空间的门。

beta5

一句问候 + 输入框 + 专家 chip，底下四个数字（文件 / 记忆 / 知识 / 产物）和专家头像。

原型 09-21

空间插画 + 标签 + 四张专家卡（hover 出介绍）+ 配置专家 + 概览三卡。任务仍在第一句话发出时才建立。

一致叫法（空间）、入口页、专家从空间里选。
我们多的专家卡的介绍（做什么 / 几步 / 交出什么）、页上直接配置专家、概览可点进数据中枢。
beta5 多的「记忆」这一档——我们没做，先要定义它是什么。
侧栏点空间行仍是开合；进入口页走 hover 的 ↗。3
会话 · 右栏

一句话之后，右栏放什么会议定了：右栏不再收集参数，只做「已收集参数的状态展示 + 对应单价」。这是这次最大的分岔。

beta5

右栏是参数分组完成度（检测类型 / 动物实验 / 生物分析 / 报告与报价，13/13）——这是我们上一版的参数面板。对话里是一段文字把参数全倒出来。

原型 09-21

右栏是报价板块：按 PK/TK · TOX · BA · ADA · 动物 · 报告分板块，行内只有「数量 × 单价」和待测物 · 方法。账不等参数齐：填一项亮一行，缺的写「去填」。

分岔点beta5 的右栏回答"参数收了多少"；我们的回答"收了什么、多少钱"。
保留参数收集面板还在（第二个 tab），文件识别的逐项确认在那儿。
撤掉「报价规则」tab——两条真规则折进板块底部，其余都是板块在做的事。
板块可折叠，默认只开第一个有待定项的。4
甲方 P0-1

传一份方案，发生了什么多模态入口（Word / PDF / 截图 / 聊天记录）、解析轨迹、每项参数的原文依据、「识别」与「确认」两态。

beta5
没有这一步参数由用户在对话里逐项打字给出；没有材料入口，没有轨迹，没有原文。

beta5 的会话从「请向用户追问 11 项」开始，用户回一段 13 项参数的文字。

原型 09-21

「已读取 BB-001 方案」：7 组 / 7 分析方法 / 37 采样事件 → 识别 11 项、2 项待确认，已计价 20 项 ¥222,860，7 项未计价（待确认 2 · 无价目 4 · 缺参数 1）各带原因。右栏每一项标「识别」，铅笔逐项确认，点来源看原文句子。

规则文件为准；机器读出来的是提议，人点过头的才是参数。
入口本地文件、项目文件库、知识库；截图走 OCR 剧本，聊天记录走要求提取。
边界只有本地上传才算材料；工单附件不读；退回会话不读。
演示材料：docs/demo/materials5
P0 方案 · 八维

读出来的东西，按八维归位工程方案第一层定了「8 维提取 Schema」。原型把材料面板按它排，每一维落到参数模型的哪个格子、哪一行账，都对得上。

P0 方案 · 第一层
  1. ① 动物→ 动物种属
  2. ② 组别→ 组数 · 核心 / 卫星
  3. ③ 数目→ 每组动物数
  4. ④ 实验操作→ 板块里的行（给药 / 采血 / 剖检…）
  5. ⑤ 操作次数→ 采血点数 · 试验周期
  6. ⑥ 检测项目→ PK/TK · TOX · ADA 板块
  7. ⑦ 检测方法→ 分析方法
  8. ⑧ 检测数量→ 每行的份数

方案第三、四、五层的几条规则也补进了原型：每化合物少于 30 份按 30 计；猴类价 / 折扣 / 其他费用是人工输入项，不假装有价目；BA Only 不问动物参数，台账写「不适用」。

原型 09-21

「输入材料」面板：按八维提取 · 读到 8 / 8 维，每一维带原文位置（§1 / 表 2 / 表 3），能展开看明细。没归到八维的（聊天记录里的交付要求）排在最后。

影响提示每次参数或单价一变，对话里一句「影响 PK / TK 样品采集 2 行；合计 A → B」——转换确认模块首期要的那一项。
没做的检测项目多选 + 按组参数（积木卡）、按组明细视图、审核人看原文依据与变更记录。
要讨论八维之外的东西（交付要求、报价区域）在方案里没有位置，原型先放在「其他」。

会议共识 1

费用怎么看，价怎么改beta5 把费用明细作为一次性输出贴在对话里；我们把它做成右栏常驻的账，单价旁就是改价。

beta5

「费用明细」卡：6 行、总价、「计算详情」按钮，再下面 xlsx / docx 两个文件。改价没有路径——要改只能重新对话。

原型 09-21

同一条路走了三种价：改价——TK 毒代采血 ¥130 → ¥120，行上挂「临时价 · 原价 · 恢复」；补价——猴类价系统没有，标「待补价」，人给 ¥30,000 只作用于本单；本单折扣 0.9——人工调整项，作用在合计上，写进纸面的黄格子。每一步对话里都留一句「仅本次报价，价目表不动」。

唯一路径改价只在板块里，不经对话、不进后台。
不按零元无价目的项留在账上标「待补价」，人补一个只作用于本单；折扣、其他费用同理，是人工项不是价目。
重出出过版之后改价，版本卡标「待重出」，一键重新生成。
纸面（Excel 计算表 / Word 报价书）读的就是这份账：Standard 按价目、Discounted 按调整后。7
会议共识 2

完整价目表不进对话独立入口给 SD；但「这单用了哪些价」可以在对话里问，回一张本单命中的表。

原型 · 对话里问

「列出本单命中的价目」→ 费用项目 / 板块 / 单价 / 本单用量 / 状态。同一档价折一行，临时价带原价，无价目另起。谁都能问，那不是完整表。

原型 · 后台

「查看完整价目表 →」进报价管理，页首一行：这里是全局，改本单回会话。SD 助理进来是只读。

beta5没有价目表的入口，也没有"这单用了哪些价"。
边界全局（底表）和本单（临时价）是两条路，文案在两头都写了。
状态保留进后台再返回，会话原样还在（今天修的）。

硬冲突 · 以我们为准

人、站内信、工单、复核beta5 里没有「人」的概念；报价审批和退回在我们这里是一条完整的链。

原型 · 站内信

待办与动态分开；工单带附件、时间线、处理人；交接从会话里一键发出。

原型 · 复核画布

审批人对着计算表 / 报价书逐行批注 → 退回修订 → 撰写人那边批注回到会话、改参数、重出 v2。

beta5没有账号角色、没有工单、没有交接——这是唯一的硬冲突。
要问的空间会不会有成员和岗位？没有的话审批和退回在 beta5 里怎么落？
我们的立场会话层同源，人与流转以我们为准。

数据中枢

文件、产物、来源会话两边都有「产物」和它来自哪条会话；beta5 多「记忆」「知识」两档。

beta5

文件 / 记忆 / 知识 / 产物四档，按空间筛，有回收站和「问问文件助手」。

原型 09-21

根级「全部文件 | 产物」分段，产物档多一列来源任务，点进那条会话。

一致产物 + 来源会话。
没做「记忆」——先问工程师它是会话级摘要还是跨会话的用户记忆，决定会话快照往哪儿接。
没改名知识库照旧。

演示级

权限，和「+」里的技能 / 连接器权限分级会上后置了；我们用账号切换器演出"同一单在 SD 和 SD 助理眼里各是什么样"。

原型 · 「+」菜单

技能 = 让数字同事现在就做（总结 / 列价目 / 核对 / 预览 / 生成，做不了的灰掉写原因）；连接器 = 本会话在读哪些源（项目文件库、计价规则库）。

原型 · 权限
SD 助理SD

赵敏 = SD 助理，王林彬 / 李林 = SD。级别显示在左下角账号行。

beta5「+」只有上传；专家是全局页的一个入口。
说服力技能不是挂在消息上的标签，是可以让它做的事；连接器回答"它读得到什么"。
待定两级够不够？会上原话是"SD 助理改临时价、SD 改底表"。

今天想带走的

三个要一起定的问题

Q1 · 颗粒度

板块 = 一行，还是一板块多项服务？

会上的例子「PK 样品采集机制：血浆 · 6 种 / ELISA / 11 只 / 0.5 USD」一板块一行；我们一个板块里有采血、方法开发、样品检测多项。行首保留了服务名，四要素在下面。

Q2 · 人

空间会不会有成员和岗位？

没有的话，报价审批、退回、交接在 beta5 里怎么落？我们这条链要接到哪个对象上。

Q3 · 记忆

数据中枢的「记忆」是什么？

会话级摘要，还是跨会话的用户记忆？决定我们的会话快照和摘要往哪儿接。另：「八维」表拿到后逐板块定字段。
