一页结论

三个差异点

01 · 架子

三列一样，名字随便叫

左边任务、中间对话、右边面板，两边一个形状。项目还是空间只是名字，想改就改。beta5 里有一样我们拿来用了：专家按空间配置。它别的那些偏框架的东西——工具页、记忆、知识——用起来不太实在，就没接。

02 · 右栏

一张固定的卡，还是一个容器

beta5 的右栏是一张「参数收集 13/13」的卡，收完就没事了。我们把右栏做成一个位置固定的容器：放什么面板、几个 tab，可以搭配；能并列、能全屏、能收起。这是从 Codex、Claude Code 那种全自由面板收回来的——那种太灵活，跟做报价这件事不贴。

03 · 工作流与对话流

一条链在会话里走完

材料进来，识别、留原文依据；参数卡按动物 / 实验 / 检测分页，缺什么问什么；右栏当场成账；改价补价；出纸；交接；对方复核；退回；再重出。这一整条在一个会话里走完。beta5 到追问参数、出一张费用卡就停了。原型花功夫的地方是这条链。

3–9 页一项一项对；10 页起是报价线上多出来的功能；第二部分是会上那几处改动的细节。·
会话层

三列是同一套左任务、中对话、右面板——beta5 的会话页也是这个形状。不一样的在右栏，还有右栏后面那条链。

beta5 · 会话

右栏一张「报价参数收集 13/13」的卡，四组完成度；参数靠打字，一段话二十项。形状跟我们一样，右栏是死的。

原型 · 会话

设计点 · 右栏

位置固定的面板容器一开始想学 Codex、Claude Code 那种想放哪放哪的面板，试了一轮：太灵活，用户得先学面板，跟报价这件事也不贴。收回来——右栏位置固定，里面是可以搭配的面板和 tab，能加、能并列、能全屏、能收起。

为什么不做全自由Codex 那种要先学怎么摆面板；做报价的人要的是"右边就该有这几样"。位置固定、内容可选，最省事。
面板和 tab常驻的几个是模块自己登记的，「+」里是备选；拖成一列、铺满、收起，状态跟会话走，切走再回来还在。
对 beta5它那张固定的卡放进这个容器就是一个常驻 tab；来源、明细、产物这些，它没地方放。
components/workbench-panel/WorkbenchPanel.tsx · 一份容器，四条业务线共用 · 这一块改的轮数最多·
同一副壳

四条业务线，一副架子DMPK 报价、肿瘤报价、QA 审核、肿瘤报告都在同一个壳里：侧栏、站内信、数据中枢、三列都一样，只有右栏登记的 tab 不一样。

原型 · QA 审核

右栏登记的是原件、AI 审核、差异、批注；中间是对话加审核画布。壳一个字没改。

原型 · 肿瘤报价

和 DMPK 报价用的是同一套参数卡、chips、台账，组件共用，字段不同；右栏是它自己的三个 tab。

模块只说一句"我要哪些面板、哪几个常驻"，容器负责摆。
样式一份参数卡那套类名两条报价线共用，改一处两边一起变——风格一致靠这个，不靠人盯。
对 beta5它一条线一个页面形态；我们加一条线，就是登记一个模块。

最重要的差异

工作流与对话流beta5 的会话是追问参数、用户打一段、出一张费用卡。我们的会话是一条链：材料进来，到报价交出去、被复核、被退回、再重出，都在这一个会话里。

beta5 · 会话

「还需要补充共 11 项信息」，用户一段话补二十项，然后「报价已生成成功」，一张费用明细卡加两个文件。参数靠打字，改价没有路径，交出去之后没有下文。

原型 · 会话

一句话或一份方案进来，解析轨迹加原文依据；参数卡按动物 / 实验 / 检测分页、缺什么问什么；右栏当场成账；改价补价；出 Word 和 Excel；交接卡交出去；对方在站内信里复核；退回的批注回到会话；重出 v2。

材料 / 一句话→识别 · 原文依据→参数卡（动物 / 实验 / 检测）→右栏成账→改价 · 补价→Word / Excel→交接→复核 · 依据与变更→退回 → 重出
每一步都在同一个会话里，右栏跟着换 tab；对话里每一步留一句话——影响了哪几行、仅本次报价。·
小地方

设计上的巧思不是功能，是让人少学一步、少点一下、少猜一次的地方。beta5 对应的位置基本是空的。

hover

动效只在该动的地方

专家卡 hover 时介绍从卡底长出来（做什么、几步、交出什么）；空间那一行 hover 才出 ↗；参数卡点卡头开合，点别处自动收。不弹、不抢。

语言

一个口径说到底

「仅本次报价，价目表不动」「影响 X 行，合计 A → B」「原文为 X，已改为 Y」——对话、右栏、纸面三处一句话，不用翻译。

风格

一套令牌管所有线

圆角、字号、时长、颜色都是令牌；参数卡那套类名两条报价线共用；跑一遍 audit 就知道哪儿走样。四条线看着是一家的。

图标

右上角两颗，各管一件事

「总结对话」把会话钉成四段，交接卡直接预填；「面板开关」收起右栏回两列。顶栏只放这两个，别的都在 tab 里。

这些都是一轮一轮改出来的，第一版没有。·

报价线 · 功能差异

报价线上 beta5 没有的四样都长在右栏和对话流里，不动壳。细节在第二部分，这里只过一眼。

A · 改价

一条路，只动这一单

单价旁的铅笔：原价、新价、确认；没价目的补价；折扣、其他费用是人工项。价目表不动，纸面跟着账走。

B · 材料

传方案，正文里溯源

Word、PDF、截图、聊天记录进来，读完在正文列出认到的每一项，hover 来源标记看原句，逐项点头；右栏留给账。机器认的是提议，人点头才算数。

参数收集和报价板块一一对应

动物、实验、检测、报告与交付四类，两边同一套；八维在下层给提取用。命中一块长一块，「再搭一块」加 TOX、BA、ADA，右栏的账同步长出来。

审核人看同一份草稿

交接带纸、原文依据、变更记录，画布多一页「依据与变更」；批完退回，批注回到会话。

第二部分 · 1

先打一句话，右边就是账会上定的：右栏不再收集参数，只放已收集参数的状态和对应单价。

说先从最简单的开始。我在输入框打一句"PK 小分子，SD 大鼠，每组 6 只，3 组，两周，血浆，中文报告"。右边这一栏现在就是会上说的那个样子了：按动物、实验、检测、报告与交付四块分，每行就一个数量乘单价，能收起来。参数还没给的行写"缺参数"，点一下过去填，不会在右边让你填。

原型 · 报价板块

右栏是账：按动物、实验、检测、报告与交付四类分板块，和参数收集那四张卡一一对应；行里只有数量 × 单价，工作包（PK/TK、TOX、ADA）写成行上的小标。账不等参数齐：填一项亮一行，缺的写「去填」。

板块能折叠，默认只开第一个有待定项的；工作包是行上的小标，不再是段头。·
第二部分 · 2

参数收集分四类，八维在下层上层是动物、实验、检测、报告与交付，跟报价板块一一对应；P0 那八维留给提取和材料面板，展示上不带序号。

说参数收集挪到旁边这个页签了，分四张卡：动物、实验、检测、报告与交付——跟右边报价板块的四块是一一对应的，给甲方的报价单也按这四类分。字段还是原来那十四个，一个没动，就是分法改了。P0 方案里那八维（动物、组别、数目、操作、次数、检测项目、方法、数量）留在下层给提取用，展示上不标序号了。

原型 · 参数收集（并列成一列）

四张卡：动物（种属、组数、每组只数）、实验（周期、样品类型、采血点数）、检测（检测类型、分子类型、化合物类别、方法、待测物数量）、报告与交付；下面是方案里读出来的别的工作包。右边「输入材料」里读出来的事实按八维排，不带序号。

八维落到四类、十四项上
  1. 动物→ 动物 · 动物种属
  2. 组别→ 动物 · 组数
  3. 数目→ 动物 · 每组动物数
  4. 实验操作→ 实验 · 样品类型；板块里的行
  5. 操作次数→ 实验 · 采血点数 · 试验周期
  6. 检测项目→ 检测 · 检测类型 · 分子类型 · 化合物类别
